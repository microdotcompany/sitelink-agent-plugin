# site.link for ChatGPT

Give the website you built with ChatGPT Sites a free address like `mycafe.site.link`, without buying a domain or touching DNS.

Ask ChatGPT:

> Give this Site a site.link address

site.link reserves the name, ChatGPT Sites adds it as a custom domain, and site.link creates the DNS records Sites asks for. The address works over HTTPS once Sites verifies it, usually within a few minutes.

Each account gets one free name. Sign in with email or Google the first time ChatGPT asks.

## What's in here

A ChatGPT plugin: the site.link MCP connector (`https://mcp.site.link/mcp`) and a skill that walks the assistant through check, claim, connect and verify. The server code is in [`sitelink-mcp`](https://github.com/microdotcompany/sitelink-mcp).
